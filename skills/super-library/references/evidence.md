# Evidence and citation boundary

Library entries support language retrieval and source discovery. They are not
citable evidence.

- Common terminology and original sentence frames need no wording citation.
- Definitions, mechanisms, historical relationships, and performance statements
  require the appropriate primary paper.
- Open each linked source and verify the exact claim, setting, version, and venue.
- If a verified source is absent from the user's bibliography, return a candidate
  source or `[CITATION NEEDED: source-id]`; never manufacture a BibTeX key.
- Static entries cannot establish what is currently latest or state of the art.
  Browse current primary sources when those claims are requested.
- Never present a paraphrase as a quotation.
- Do not copy abstracts, Related Work sentences, or extended source wording.
- When methods use different data, compute, metrics, splits, or evaluation
  protocols, disclose the mismatch instead of writing a direct superiority claim.

Before delivery, ask of every technical sentence: is it supplied by the user,
derived transparently from supplied facts, or verified in a primary source? If
none applies, qualify it or mark it for citation.
